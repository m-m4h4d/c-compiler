Compiler Source

A compiler for a subset of C, written in Python

It reads C source and produces three-address code and LLVM IR that clang turns into a native program. Paste a program into the compiler to see what each phase makes of it.

One line, six phases

Here is what the compiler does with int b = 5 + 3; inside main.

  1. 1

    Lexer lexer.py

    Splits the source into tokens, skipping whitespace and comments.

    INT     int
ID      b
ASSIGN  =
NUMBER  5
PLUS    +
NUMBER  3
SEMI    ;
  2. 2

    Parser parser.py

    Builds a syntax tree by recursive descent, with one function for each level of operator precedence.

    VarDecl int b
└── init_expr: BinOp +
    ├── left: Number 5
    └── right: Number 3
  3. 3

    Semantic analysis semantic.py

    Checks every name against a stack of scopes, and catches redeclarations, undeclared names and misused arrays and functions.

    block scope in main
  b    int    declared here
  4. 4

    Optimizer optimizer.py

    Folds constant expressions the way C evaluates them and removes code that can never run.

    VarDecl int b
└── init_expr: Number 8
  5. 5

    Three-address code tac.py

    Flattens the tree into simple instructions with temporaries and labels.

    b = 8
  6. 6

    LLVM IR codegen.py

    Emits LLVM IR, which clang compiles and links into an executable.

    %b.addr1 = alloca i32
store i32 8, i32* %b.addr1

What it compiles

  • int, float and double, with C's implicit conversions
  • Functions with parameters, recursion and void return types
  • if and else, while, and for with a declaration in its first clause
  • Arithmetic, comparison and logical operators, with && and || evaluated lazily
  • Prefix and postfix ++ and --
  • One-dimensional arrays, local and global variables, and block scoping
  • // and /* */ comments

What it leaves out

  • Pointers, structs, char and strings, so programs report their result through the exit code
  • break, continue, do and switch
  • Compound assignment such as +=
  • Multi-dimensional arrays and array initializers
  • Literals such as .5 and 1e5

Run a program on your machine

The website shows the compiler's output but doesn't execute it. To run a program, compile it locally with Python 3 and clang.

python compiler/main.py program.c   # writes output.tac and output.ll
clang output.ll -o program
./program; echo $?                   # the exit code is main's return value
